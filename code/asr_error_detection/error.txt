AttributeError: 'NoneType' object has no attribute 'encoders'
I see exactly what is happening here! This is a classic caching bug.
The Cause
Because you ran the script previously and it successfully cached the Text-NLU inferences, the pipeline is smartly loading those saved results from disk to save time. However, by skipping the Text-NLU forward inference step, the script never initializes the self.text_engine object.
Later in the loop, when it tries to extract features and requests self.text_engine.encoders, the object is None, which immediately triggers the AttributeError.
The Fix
Instead of forcing the engine to initialize (which takes time), we just need to load the text_encoders directly from your saved artifacts so they are always available regardless of whether the cache is used.
Open your run_master_exp.py file and make these two quick replacements.
